= Amazon FSx for NetApp ONTAP 的配置分析
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Console 中的架构完善仪表板定期分析存储系统配置，以确定您的 Amazon FSx for NetApp ONTAP 文件系统是否存在任何配置问题。发现问题时，仪表板会向您显示问题所在，并解释需要更改的内容，以确保您的存储系统实现最佳性能、成本效益和最佳实践合规性。

主要功能包括：

* 每日配置分析
* 针对 NetApp ONTAP 存储系统和合作伙伴存储提供商的自动最佳实践验证
* 主动可观察性
* 从见解到行动


未解析的指令，位于 <stdin> - include::well-architected-workloads.adoc[]



[[analysis-requirements]]
== 分析要求

要进行完整的文件系统分析，必须执行以下操作：

* link:https://docs.netapp.com/us-en/console-setup-admin/concept-agent-install-options.html#agent-console-deploy["部署 NetApp Console agent"^] 或 link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-link.html["关联链接"^] 以设置文件系统与 NetApp Console 之间的连接。
* 在您的 AWS 账户中授予查看、规划和分析权限。
+
link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html["了解如何向 AWS 帐户授予权限"^]
